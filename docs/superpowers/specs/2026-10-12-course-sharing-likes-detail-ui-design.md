# 코스 공개·좋아요·상세 UI 설계

## 1. 목적

사용자가 만든 코스를 다른 사용자에게 공유하고, 공개 코스를 찜해 다시 찾을 수 있게 한다. 코스 상세 화면은 참고 UI의 구조를 따르되 현재 소품지도에 존재하는 정보와 동작만 사용한다.

이번 범위에는 공유 링크로 공개 코스를 열고 좋아요하는 흐름까지 포함한다. 공개 코스 탐색·검색 화면과 추천 코스 관리 화면은 포함하지 않는다.

## 2. 코스 종류와 작성자

### 사용자 생성 코스

- `courseType: "user_created"`를 사용한다.
- `Course.userId`가 작성자를 가리킨다.
- 작성자 표시는 `by {사용자 닉네임}`이다.
- 작성자가 탈퇴했으면 `by 알 수 없는 사용자`로 표시한다.
- 새 코스는 기본적으로 비공개다.
- 작성자만 공개 여부를 바꾸고 코스를 수정·삭제할 수 있다.

### 소품지도 추천 코스

- `courseType: "recommended"`를 사용한다.
- 사용자 작성자를 필요로 하지 않는다.
- 작성자 표시는 `by 소품지도`다.
- 항상 공개 상태로 취급한다.
- 일반 사용자가 좋아요할 수 있다.
- 일반 사용자 화면에는 공개 전환·수정·삭제 기능을 제공하지 않는다.

`SHOP_SOURCE_TYPES`는 상점 정보 출처 전용이므로 코스 작성자나 권한을 표현하는 데 재사용하지 않는다. 사용자 모델에 관리자 역할도 추가하지 않는다.

## 3. 공개 범위 정책

- `Course.isPublic`은 사용자 생성 코스의 공개 범위 필드다.
- 작성자는 비공개 코스도 조회할 수 있다.
- 작성자가 아닌 사용자는 공개 코스만 조회할 수 있다.
- 비공개 코스 상세 접근에는 `403 COURSE_PRIVATE`를 반환한다.
- 추천 코스는 `isPublic` 값과 관계없이 공개 코스로 다룬다. 저장 데이터도 공개 상태를 유지한다.
- 공개에서 비공개로 바꿀 때는 확인 바텀시트를 표시한다.
- 비공개에서 공개로 바꿀 때는 즉시 반영한다.

공개 코스를 비공개로 바꿔도 기존 좋아요 기록은 삭제하지 않는다. 다시 공개하면 기존 좋아요와 좋아요 수가 그대로 복구된다.

## 4. 코스 좋아요 모델

좋아요는 별도 `CourseLike` 컬렉션에 저장한다.

```text
CourseLike
├─ userId: ObjectId
├─ courseId: ObjectId
├─ createdAt
└─ updatedAt
```

인덱스와 규칙:

- `{ userId: 1, courseId: 1 }` 고유 인덱스로 중복 좋아요를 막는다.
- 사용자 찜 목록을 위해 `{ userId: 1, createdAt: -1, _id: -1 }` 인덱스를 둔다.
- 코스별 좋아요 집계를 위해 `{ courseId: 1 }` 인덱스를 둔다.
- 본인이 만든 사용자 코스에는 좋아요할 수 없다.
- 공개된 다른 사용자 코스와 추천 코스에만 새 좋아요를 추가할 수 있다.
- 비공개 코스에는 새 좋아요를 추가할 수 없다.
- 기존에 좋아요한 코스가 비공개가 되어도 찜 해제할 수 있다.
- 중복 좋아요 요청은 기존 상태를 유지하는 멱등 동작으로 처리한다.
- 코스를 삭제할 때 연결된 `CourseLike`도 삭제한다.

좋아요 수는 `Course` 문서에 중복 저장하지 않고 `CourseLike`에서 집계한다. 목록 조회에서는 코스마다 따로 집계하지 않고 한 번의 집계 쿼리로 N+1 조회를 피한다.

## 5. API 계약

### 코스 상세

`GET /api/courses/:courseId`

기존 상세 정보에 다음 값을 추가한다.

```text
author
├─ id: string | null
├─ displayName: string
├─ profileImageUrl: string | null
└─ isService: boolean

isOwner: boolean
isPublic: boolean
likeCount: number
isLiked: boolean
```

- 추천 코스의 `author.id`는 `null`, `displayName`은 `소품지도`, `isService`는 `true`다.
- 사용자 생성 코스는 현재 사용자와 작성자를 비교해 `isOwner`를 계산한다.
- 작성자 본인에게도 `likeCount`를 반환한다.
- 작성자 본인의 코스에서는 `isLiked`가 항상 `false`다.

### 좋아요

- `POST /api/courses/:courseId/likes`: 공개 코스 좋아요
- `DELETE /api/courses/:courseId/likes`: 좋아요 해제

오류 정책:

- 본인 코스 좋아요: `400 COURSE_SELF_LIKE_NOT_ALLOWED`
- 비공개 코스 신규 좋아요: `403 COURSE_PRIVATE`
- 존재하지 않는 코스: `404 COURSE_NOT_FOUND`

좋아요 해제는 현재 코스가 비공개여도 허용한다. 이미 좋아요가 없어도 성공으로 처리한다.

### 공개 여부

`PATCH /api/courses/:courseId/visibility`

```json
{
  "isPublic": true
}
```

- 사용자 생성 코스의 작성자만 변경할 수 있다.
- 타인의 코스 또는 추천 코스 변경은 `403 COURSE_FORBIDDEN`을 반환한다.

### 내 코스 목록

`GET /api/me/courses?cursor={cursor}&limit=20`

- 내가 만든 사용자 코스를 생성일 내림차순으로 반환한다.
- 항목에는 공개 여부와 받은 좋아요 수를 포함한다.
- 한 번에 기본 20개를 반환한다.

### 찜한 코스 목록

`GET /api/me/liked-courses?cursor={cursor}&limit=20`

- 좋아요한 시각 내림차순으로 반환한다.
- 공개 코스는 제목, 대표 이미지, 지역, 상점 수, 작성자, 좋아요 수를 반환한다.
- 비공개 코스는 식별자, 비공개 여부, 좋아요 식별에 필요한 최소 정보만 반환한다.
- 비공개 코스의 제목, 설명, 지역, 사진, 상점, 작성자, 좋아요 수를 노출하지 않는다.
- 삭제된 코스의 좋아요는 함께 삭제되므로 목록에 남기지 않는다.

두 목록은 시간과 `_id`를 함께 사용하는 불투명 커서로 페이지를 구분한다. 응답에는 `items`, `nextCursor`, `hasNext`를 포함한다.

## 6. 코스 상세 화면

### 상단 영역

- 왼쪽에 뒤로가기 버튼을 둔다.
- 오른쪽에 공유 버튼을 둔다.
- 작성자 본인의 사용자 생성 코스에만 더보기 버튼을 둔다.
- 더보기 바텀시트에는 `코스 수정`, `코스 삭제`를 제공한다.
- 기존 하단 고정 `삭제 / 코스 수정` 영역은 제거한다.

공유 버튼은 Web Share API를 우선 사용한다. 지원하지 않으면 현재 코스 주소를 클립보드에 복사하고 스낵바로 알린다.

### 제목과 작성자

- 코스 제목과 설명을 표시한다.
- 사용자 작성자는 프로필 이미지와 `by {닉네임}`을 표시한다.
- 추천 코스는 서비스 기본 이미지와 `by 소품지도`를 표시한다.

### 공개 상태와 좋아요

- 내 사용자 생성 코스: 좋아요 버튼 없이 공개 상태 스위치와 받은 좋아요 수를 표시한다.
- 다른 사용자의 공개 코스: 좋아요 버튼과 좋아요 수를 표시한다.
- 추천 코스: 좋아요 버튼과 좋아요 수를 표시한다.
- 공개에서 비공개로 바꿀 때 확인 바텀시트를 표시한다.

### 지도와 방문 순서

- 지도는 현재 고정 직선 미리보기 정책을 유지한다.
- 방문 순서는 순서 원형과 세로 연결선으로 구성한다.
- 소품샵 사진, 상점명, 주소, 메모를 유지한다.
- 구간 사이에는 저장된 도보 거리와 예상 소요 시간을 `도보 8분 · 620m` 형태로 표시한다.
- 방문 시각은 서비스 데이터에 없으므로 표시하지 않는다.
- 상점 행의 오른쪽 화살표를 누르면 바텀시트를 연다.
- 상점 바텀시트에는 `상점 보기`, `길찾기`를 제공한다.
- 각 상점 행에는 사용자별 방문 상태를 바꾸는 `방문했어요` 버튼을 둔다.
- 방문 체크와 선택적인 방문 로그 연결은 `2026-10-15-course-shop-visit-design.md`를 따른다.

## 7. 내 산책 코스 화면

화면 상단에 `내 코스 / 찜한 코스` 두 탭을 둔다.

### 내 코스 탭

- 내가 만든 사용자 코스를 표시한다.
- 공개 여부와 받은 좋아요 수를 표시한다.
- 20개 단위 무한 스크롤을 사용한다.

### 찜한 코스 탭

- 공개 코스에는 제목, 대표 이미지, 지역, 상점 수, 작성자와 좋아요 수를 표시한다.
- 비공개 코스는 이미지와 세부 정보 없이 `비공개 코스`로 표시한다.
- 비공개 항목을 누르면 `작성자가 비공개한 코스입니다.` 스낵바를 표시한다.
- 비공개 항목에서도 좋아요를 해제할 수 있다.
- 20개 단위 무한 스크롤을 사용한다.

## 8. 프론트엔드 상태 동기화

좋아요와 공개 상태 변경은 낙관적으로 화면에 먼저 반영한다. 요청이 실패하면 이전 상태로 되돌리고 스낵바로 오류를 알린다.

변경 성공 후 다음 React Query 캐시를 함께 갱신한다.

- 해당 코스 상세
- 내 코스 목록
- 찜한 코스 목록

비공개 전환으로 다른 사용자의 상세 요청이 `COURSE_PRIVATE`를 반환하면 일반 오류 화면 대신 비공개 안내를 표시한다.

## 9. 접근성과 반응형

- 아이콘 버튼에는 `aria-label`을 제공한다.
- 탭은 키보드로 이동하고 선택 상태를 보조 기술에 전달한다.
- 바텀시트는 공용 `BottomSheet`를 사용해 포커스 이동, 바깥 스크롤 잠금과 닫기 동작을 유지한다.
- 좋아요와 공개 여부는 색상뿐 아니라 텍스트와 접근 가능한 이름으로 구분한다.
- 320px, 390px, 480px 화면에서 제목, 작성자, 액션과 상점 정보가 겹치지 않게 한다.

## 10. 테스트 범위

### 백엔드

- `CourseLike` 모델의 중복 방지와 인덱스
- 본인 코스, 공개 코스, 비공개 코스, 추천 코스별 좋아요 권한
- 비공개 전환 후 기존 좋아요 유지
- 비공개 코스 좋아요 해제
- 공개 여부 변경 권한
- 작성자, 좋아요 수와 현재 사용자 상태 상세 매핑
- 내 코스와 찜한 코스의 20개 커서 페이지네이션
- 비공개 찜 항목의 정보 차단
- 코스 삭제 시 좋아요 정리

### 프론트엔드

- 내 코스, 타인 코스, 추천 코스별 상세 액션
- 좋아요 낙관적 갱신과 실패 복구
- 공개 전환 확인 바텀시트
- 상점 액션 바텀시트
- 내 코스와 찜한 코스 탭 및 무한 스크롤
- 비공개 찜 카드와 찜 해제
- 320px, 390px, 480px 반응형
- 키보드 조작, 포커스와 접근 가능한 이름

## 11. 제외 범위

- 공개 코스 탐색·검색 화면
- 추천 코스 등록·수정·삭제 관리 화면
- 사용자 관리자 역할과 관리자 화면
- 코스 신고
- 댓글과 팔로우
- 실제 도보 경로 형상 표시

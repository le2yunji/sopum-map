# 코스 상세 바텀 시트 정렬·디자인 통일 설계

## 의도

코스 지도에서 방문 순서 시트와 코스 수정·삭제 시트가 같은 UI 계열로 보이게 하고, 각 시트가 지도와 코스 정보 오버레이를 가리는 높이를 예측 가능하게 맞춘다.

## 목표

- 펼친 방문 순서 시트의 윗선을 열린 코스 정보 오버레이의 윗선과 맞춘다.
- 코스 수정·삭제 시트의 높이를 접힌 방문 순서 시트 높이인 200px와 맞춘다.
- 두 시트의 상단 모서리, 손잡이, 그림자와 기본 여백을 방문 순서 시트 디자인 기준으로 통일한다.
- 키보드 닫기, 배경 클릭 닫기, 드래그 같은 기존 동작은 유지한다.

## 범위 밖

- 다른 화면에서 사용하는 공용 BottomSheet의 전역 디자인은 바꾸지 않는다.
- 방문 순서 시트의 접힘 높이 200px와 드래그 전환 규칙은 바꾸지 않는다.
- 코스 수정·삭제 동작과 데이터 요청은 바꾸지 않는다.

## 구현 방향

선택한 방식은 방문 순서 시트를 디자인 기준으로 삼는 방식이다. 코스 상세 화면 안에서 재사용할 시트 표면 스타일을 한곳에 두고 방문 순서 시트와 수정·삭제 시트가 공유한다. 코스 정보 오버레이의 실제 윗선은 화면에서 측정해 방문 순서 시트에 전달하므로 안전 영역과 화면 너비가 달라도 같은 선에 맞는다. 정보 오버레이가 닫혀 있을 때는 기존 고정 오프셋을 대체하는 안정적인 기본값을 사용한다.

대안으로 공용 BottomSheet 전체를 변경하는 방법은 다른 화면까지 영향을 주므로 제외한다. 두 컴포넌트에 같은 클래스를 각각 복사하는 방법은 당장은 빠르지만 이후 다시 달라질 수 있어 제외한다.

## 검증

- Storybook에서 방문 순서 시트를 펼쳤을 때 코스 정보 오버레이와 윗선이 일치하는지 확인한다.
- 더보기 시트의 높이가 접힌 방문 순서 시트의 200px와 일치하는지 확인한다.
- 두 시트의 손잡이와 시트 표면 스타일이 같은지 확인한다.
- 기존 코스 상세 상호작용 테스트, 린트와 타입 검사를 실행한다.

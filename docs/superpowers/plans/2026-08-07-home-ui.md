# Home UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement issue #68 as a resilient mobile home screen with curation, category filtering, shops, recommended courses, and four-tab navigation using local display fixtures.

**Architecture:** Move the root home route into the existing `(main)/(tabs)` route group so navigation is shared by later screens. Keep fixtures, display components, and interactive category state separate; model loading, empty, and error states explicitly so API integration can replace fixtures without rewriting the page.

**Tech Stack:** Next.js 16.2.12 App Router, React 19.2.4, TypeScript 5, Tailwind CSS 4, Storybook 10, Vitest browser mode, Playwright

## Global Constraints

- Implement issue #68 only; real API requests and persisted likes remain outside this PR.
- Reuse `ShopBannerCarousel`, `FilterChipGroup`, `ShopCard`, `CourseListItem`, `Skeleton`, and project tokens.
- Support 320px, 390px, and 480px widths with keyboard-accessible horizontal scrolling and controls.
- Model `loading`, `success`, `empty`, and `error` separately; one section failure must not remove navigation or other sections.
- Add purpose comments above new functions and keep fixture transformation outside rendering components.
